# Automação de envio de e-mails com n8n

## Sobre o projeto

Projeto de automação desenvolvido utilizando n8n, integrado ao Google Forms, Google Sheets e Gmail.

O objetivo é automatizar o processamento de respostas recebidas por meio de formulários e realizar o envio de e-mails automaticamente.

## Tecnologias utilizadas

- n8n
- Google Forms
- Google Sheets
- Gmail

## Como funciona?

1. O usuário preenche o formulário do Google Forms.
2. As respostas são armazenadas automaticamente no Google Sheets.
3. O n8n identifica quando uma nova linha é adicionada à planilha.
4. O workflow processa as informações recebidas.
5. O Gmail envia um e-mail automaticamente.

## Fluxo da automação

Google Forms → Google Sheets → n8n → Gmail

## Objetivo do projeto

Explorar integrações entre ferramentas, automação de processos e comunicação entre diferentes serviços.

## Como utilizar

1. Baixe o arquivo JSON do workflow.
2. Importe o arquivo no n8n.
3. Configure suas próprias credenciais do Google Sheets e Gmail.
4. Ajuste os dados conforme sua necessidade.
6. Execute e teste a automação.
